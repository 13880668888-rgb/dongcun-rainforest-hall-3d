# Rainforest Hall Material Concept V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce and verify an editable Blender V2 material-concept model, GLB, three daylight previews, and a machine-readable dimension report from the existing V1 `.blend` baseline.

**Architecture:** Blender 5.1.2 opens `models/source/rainforest-hall-white-v1.blend` directly, validates its locked scene properties, adds V2 content in new collections, and writes only V2 outputs. A separate Blender validation pass reopens the saved V2 file, checks locked dimensions, required objects/cameras, rendered images, GLB header, and replacement metadata.

**Tech Stack:** Blender 5.1.2 Python API, Cycles/Eevee rendering, glTF 2.0, Python `unittest`, JSON.

**Spec:** `docs/superpowers/specs/2026-08-30-rainforest-hall-3d-design.md`

## Global Constraints

- V1 `.blend` is the sole geometry baseline and must never be overwritten.
- Locked values remain: 14.80 m clear width, 25.00 m clear length, constant width, 4.00 m stage height, 4.80 m entrance frame, and 2.20 m double-door clearance.
- Preserve the pitched roof and right-side opening.
- Add only Stage-B concept content; provisional geometry is not construction information.
- Do not touch any other repository or OpenClaw/BeeLink project.
- Every `.blend`, `.glb`, and preview must be generated by Blender 5.1.2.
